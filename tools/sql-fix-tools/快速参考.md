## 🔧 常用修复模式

### 1. CONCAT转换
```sql
-- Oracle
'text1' || 'text2'
'text' || CHAR(10) || 'text2'

-- MySQL
CONCAT('text1', 'text2')
CONCAT('text', CHAR(10), 'text2')
```

### 2. Oracle函数
```sql
-- Oracle
sysdate
to_timestamp('01-01-2020', 'dd-mm-yyyy')

-- MySQL
CURRENT_TIMESTAMP
STR_TO_DATE('01-01-2020', '%d-%m-%Y')
```

### 3. 保留字
```sql
-- Oracle
describe VARCHAR(100)

-- MySQL
`describe` VARCHAR(100)
```
