### 3. Row size too large 错误

**受影响文件**:
- gzlry_HR_PHYSICAL_EXAMINE.sql

**问题根源**:
该表有265个VARCHAR列,即使将部分大字段转换为TEXT,总行大小仍然超过MySQL的65535字节限制。

**建议解决方案**:
1. **选项A - 降低VARCHAR阈值**: 修改`sql_syntax_fixer.py`中的`_fix_large_varchar`方法,将阈值从1000降低到500或更低
2. **选项B - 表拆分**: 将这个表拆分为多个相关表
3. **选项C - 使用Barracuda文件格式**: 
   ```sql
   SET GLOBAL innodb_file_format=Barracuda;
   SET GLOBAL innodb_file_per_table=ON;
   CREATE TABLE ... ROW_FORMAT=COMPRESSED;
   ```
