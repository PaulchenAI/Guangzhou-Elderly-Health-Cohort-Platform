# 变更：添加 HIS 接口访问控制配置

## 为什么

当前系统提供了文档 API 查询接口，可以查询 `docs/his/openapi.json` 中定义的所有 HIS 接口信息。但是，并不是所有的接口都应该被查询和访问。为了控制哪些接口可以被访问，需要：

1. 在配置文件中增加接口访问控制配置参数
2. 后台读取配置参数，只有配置为 `true` 的接口才可以被查询和访问
3. 默认情况下，只有指定的 14 个接口可以访问

## 变更内容

- **新增**：HIS 接口访问控制配置
  - 在环境变量或配置文件中添加接口访问控制配置
  - 配置格式：以 `operation_id` 为 key，布尔值为 value 的字典或 JSON 字符串
  - 默认配置：14 个允许访问的接口设置为 `true`

- **修改**：文档 API 查询服务
  - 在 `get_endpoints_list` 函数中过滤不可访问的接口
  - 在 `get_endpoint_detail` 函数中检查接口访问权限
  - 在 `search_endpoints` 函数中过滤不可访问的接口

- **新增**：接口访问权限检查函数
  - 提供统一的接口访问权限检查逻辑
  - 支持从配置文件读取访问控制配置

## 影响

- **受影响规范**：
  - `doc-api`：修改接口列表查询、接口详情查询和接口搜索的需求，增加访问控制

- **受影响代码**：
  - `backend-django/core/doc_api/doc_api_service.py`：添加访问控制逻辑
  - `backend-django/application/settings.py`：添加配置项（如果需要）
  - 环境配置文件：添加 `HIS_API_ACCESS_CONTROL` 配置项

- **默认可访问的接口列表**：
  1. ENC_INP_0001 - 住院就诊信息
  2. CLI_INP_0001 - 住院患者过敏信息
  3. DIAG_INP_0001 - 住院患者诊断信息
  4. CLI_INP_0010 - 手术麻醉安排信息
  5. CLI_INP_0006 - 住院草药医嘱明细信息
  6. CLI_INP_0005 - 患者抗菌药物用药目的信息
  7. CLI_NIS_0002 - 体征数据变化信息(支持多院区)
  8. CLI_NIS_0001 - 体征数据明细信息
  9. CLI_NIS_0021 - 获取压疮记录上报接口
  10. MEDINSUR_EMR_0006 - 住院电子病历死亡记录（医保）
  11. FIN_INP_0009 - 住院账单明细接口
  12. ENC_OUTP_0001 - 门诊患者就诊信息
  13. CLI_OUTP_0004 - 患者门诊处方发药信息接口
  14. PER_OUTP_0002 - 门诊患者基本健康信息接口
