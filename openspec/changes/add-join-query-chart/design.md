# 设计文档：联合查询图表可视化

## 上下文

联合查询功能已经实现了多表关联查询和数据展示，用户可以在表格中查看查询结果。现在需要添加图表可视化能力，让用户能够将查询结果转换为图表形式展示。

## 目标 / 非目标

### 目标
- 支持将联合查询结果转换为图表展示
- 支持多种常用图表类型（柱状图、折线图、饼图、散点图、条形图）
- 提供友好的字段选择和图表配置界面
- 支持表格视图和图表视图之间的切换

### 非目标
- 不支持实时数据更新（图表基于当前查询结果快照）
- 不支持复杂的自定义图表配置（如自定义主题、动画等高级配置）
- 不支持 PDF 导出（仅支持 PNG 导出）

## 决策

### 决策 1：使用现有 ECharts 封装

**选择**：使用项目中已有的 `@vben/plugins/echarts` 封装

**理由**：
- 项目已集成 ECharts 5.6.0
- 已有封装好的 `useEcharts` hook 和 `EchartsUI` 组件
- 支持暗色模式自动切换
- 代码示例充足，易于使用

**考虑的替代方案**：
- 直接使用原生 ECharts：需要重复实现暗色模式、响应式等逻辑
- 使用其他图表库（如 Chart.js）：需要新增依赖，增加项目复杂度

### 决策 2：数据转换策略

**选择**：在前端进行数据转换，将表格数据转换为 ECharts 所需格式

**理由**：
- 查询结果已包含所有数据，无需额外 API 调用
- 前端转换响应速度快
- 支持实时预览和配置调整

**数据转换流程**：
1. 用户选择字段（X 轴、Y 轴、分类字段等）
2. 根据图表类型，提取和转换数据
3. 生成 ECharts option 配置
4. 渲染图表

**考虑的替代方案**：
- 后端转换：需要新增 API，增加延迟，不利于实时预览

### 决策 3：字段类型识别

**选择**：基于字段元信息（`field_info`）和字段值推断类型

**识别策略**：
- **数值字段**：字段类型为 `int`、`float`、`decimal` 等，或字段值全为数字
- **分类字段**：字段值唯一值数量较少（< 20），或字段类型为 `varchar`、`text` 等
- **时间字段**：字段类型为 `datetime`、`date`、`timestamp` 等，或字段值符合时间格式

**理由**：
- 利用已有的 `field_info` 元信息
- 结合字段值进行智能推断，提高准确性
- 无需用户手动指定字段类型

### 决策 4：图表类型与字段映射

**选择**：根据选择的字段数量和类型，智能推荐图表类型

**映射规则**：
- **1 个分类字段**：推荐饼图、柱状图
- **1 个数值字段**：推荐柱状图（按行索引）
- **1 个分类 + 1 个数值**：推荐柱状图、折线图、饼图
- **2 个数值字段**：推荐散点图
- **1 个时间 + 1 个数值**：推荐折线图

**理由**：
- 降低用户学习成本
- 提供合理的默认配置
- 用户仍可手动选择其他图表类型

### 决策 5：大数据量处理

**选择**：限制图表展示的数据点数量（最多 1000 个）

**策略**：
- 如果数据行数 > 1000，提示用户并建议：
  - 添加过滤条件缩小范围
  - 使用数据聚合（如按分类字段分组）
- 对于超过限制的数据，自动采样或聚合

**理由**：
- 避免图表渲染性能问题
- 保持界面响应速度
- 提供明确的用户提示

## 风险 / 权衡

### 风险 1：数据转换复杂度

**风险**：不同图表类型需要不同的数据格式，转换逻辑可能复杂

**缓解措施**：
- 为每种图表类型创建独立的转换函数
- 使用 TypeScript 类型约束，确保类型安全
- 编写单元测试覆盖各种数据场景

### 风险 2：字段类型识别准确性

**风险**：自动识别可能不准确，导致图表展示错误

**缓解措施**：
- 提供字段类型手动选择选项
- 在图表配置面板中显示识别结果，允许用户调整
- 对于无法识别的字段，提供默认处理方式

### 风险 3：性能问题

**风险**：大数据量时，数据转换和图表渲染可能较慢

**缓解措施**：
- 限制数据点数量（最多 1000 个）
- 使用数据采样或聚合
- 添加加载状态提示
- 考虑使用 Web Worker 进行数据转换（如需要）

## 实现细节

### 组件结构

```

├── index.vue                    # 主页面（添加图表切换）
├── components/
│   ├── ChartViewer.vue          # 图表视图组件
│   ├── FieldSelector.vue       # 字段选择器
│   ├── ChartTypeSelector.vue    # 图表类型选择器
│   └── ChartConfigPanel.vue    # 图表配置面板
└── utils/
    └── chart-data-transformer.ts  # 数据转换工具
```

### 数据转换函数签名

```typescript
// 转换表格数据为 ECharts 格式
function transformToChartData(
  items: any[],                    // 查询结果数据
  fieldInfo: FieldInfo[],          // 字段元信息
  chartType: ChartType,            // 图表类型
  xAxisField?: string,             // X 轴字段
  yAxisFields: string[],           // Y 轴字段（支持多个）
  categoryField?: string           // 分类字段
): EChartsOption
```

### 状态管理

- 使用组件内部状态管理图表配置
- 图表配置支持保存到 localStorage（与查询配置分开存储）
- 表格视图和图表视图共享查询结果数据

### 决策 6：图表导出功能

**选择**：支持 PNG 格式导出，使用 ECharts 的 `getDataURL` API

**理由**：
- ECharts 原生支持 PNG 导出，无需额外依赖
- PNG 格式通用性好，适合报告和文档使用
- 导出速度快，用户体验好

**实现方式**：
- 调用 `chartInstance.getDataURL({ type: 'png', pixelRatio: 2 })` 获取图片数据
- 创建下载链接，触发浏览器下载

**考虑的替代方案**：
- PDF 导出：需要额外依赖（如 jsPDF），增加复杂度，暂不支持

### 决策 7：图表配置保存和加载

**选择**：使用 localStorage 存储图表配置，与查询配置分开管理

**存储结构**：
```typescript
interface ChartConfig {
  id: string;
  name: string;
  chartType: ChartType;
  xAxisField?: string;
  yAxisFields: string[];
  categoryField?: string;
  chartOptions: {
    title?: string;
    legend?: boolean;
    // 其他配置选项
  };
  createdAt: string;
}
```

**理由**：
- localStorage 简单易用，无需后端支持
- 配置与查询配置分开，避免混淆
- 支持配置命名和列表管理

**存储键名**：`join-query-chart-configs`

### 决策 8：多系列图表支持

**选择**：支持选择多个 Y 轴字段，每个字段作为一个数据系列

**实现方式**：
- Y 轴字段选择器支持多选
- 数据转换时，为每个 Y 轴字段生成一个 series
- 支持为不同系列设置不同的图表类型（如柱状图+折线图组合）
- 每个系列使用不同的颜色和图例

**理由**：
- 满足对比多个指标的需求
- 提供更灵活的数据展示方式
- ECharts 原生支持多系列，实现简单

**示例场景**：
- 同时展示销售额和利润两个指标
- 使用柱状图显示销售额，折线图显示利润趋势
