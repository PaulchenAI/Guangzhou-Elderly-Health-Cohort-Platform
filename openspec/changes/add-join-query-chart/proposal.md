# 变更：联合查询图表可视化功能

## 为什么

当前联合查询功能已经实现了多表关联查询和数据表格展示，但缺少数据可视化能力。用户在执行联合查询后，需要将数据以图表形式展示，更直观地理解数据趋势和关系。项目已集成 ECharts 5.6.0 并提供了封装好的组件，具备技术基础。添加图表可视化功能可以：

1. **满足数据可视化需求**：用户可以在系统内直接进行数据可视化，无需导出到其他工具
2. **提升用户体验**：图表能更好地展示数据分布、趋势和对比关系
3. **完善功能闭环**：联合查询功能已具备数据查询能力，添加可视化能力可以形成完整的数据分析工作流

如果不做这个变更，用户需要手动将数据导出到 Excel 或其他工具进行图表分析，无法在系统内直接进行数据可视化，降低了联合查询功能的实用价值。

## 变更内容

### 1. 新增图表功能入口

在联合查询结果页面添加"图表展示"按钮，用户可以在查询结果后选择进入图表模式。

### 2. 字段选择功能

- 用户可以选择一个或多个字段用于图表展示
- 支持数值字段和分类字段的选择
- 提供字段类型智能识别和建议

### 3. 图表类型选择

支持以下图表类型：
- **柱状图**：适用于分类数据对比
- **折线图**：适用于趋势分析
- **饼图**：适用于占比分析
- **散点图**：适用于相关性分析
- **条形图**：适用于横向对比

### 4. 数据转换逻辑

- 自动识别字段类型（数值、分类、时间等）
- 根据选择的字段和图表类型，自动转换数据格式
- 支持数据聚合（求和、平均值、计数等）

### 5. 图表配置界面

- 提供图表配置面板，允许用户自定义：
  - X 轴/Y 轴字段
  - 图例显示
  - 颜色主题
  - 标题和标签

### 6. 图表与表格切换

- 支持在表格视图和图表视图之间切换
- 保持查询条件和数据状态

### 7. 图表导出功能

- 支持将图表导出为 PNG 图片格式
- 导出图片包含完整的图表内容和配置

### 8. 图表配置保存和加载

- 用户可以将图表配置（字段选择、图表类型、配置选项等）保存到本地
- 支持加载已保存的配置，快速恢复图表设置
- 配置与查询配置分开管理

### 9. 多系列图表支持

- 支持选择多个 Y 轴字段，创建多系列图表
- 用户可自由选择 X 轴字段和多个 Y 轴字段
- 每个 Y 轴字段作为一个数据系列显示
- 支持为不同系列设置不同的图表类型（如柱状图+折线图组合）

## 影响

### 受影响规范
- `join-query-frontend`：新增图表可视化相关需求

### 受影响代码
- `web/apps/web-ele/src/views/join-query/index.vue`：添加图表功能入口和切换逻辑
- 新增组件：
  - `web/apps/web-ele/src/views/join-query/components/ChartViewer.vue`：图表视图组件
  - `web/apps/web-ele/src/views/join-query/components/ChartConfigManager.vue`：图表配置管理器
- 新增工具：
  - `web/apps/web-ele/src/views/join-query/utils/chart-data-transformer.ts`：数据转换工具
  - `web/apps/web-ele/src/views/join-query/utils/chart-export.ts`：图表导出工具

### 依赖
- 已存在：`@vben/plugins/echarts`（ECharts 封装）
- 已存在：`echarts@5.6.0`

### 性能考虑
- 图表渲染使用 ECharts，性能良好
- 大数据量时建议限制图表展示的数据点数量（如最多 1000 个数据点）
