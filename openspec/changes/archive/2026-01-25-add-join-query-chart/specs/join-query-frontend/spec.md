## 新增需求

### 需求：图表展示功能入口

系统必须在联合查询结果页面提供图表展示功能入口。

#### 场景：显示图表按钮

- **当** 用户执行联合查询并获得结果
- **那么** 在工具栏中显示"图表展示"按钮
- **并且** 按钮位于"导出数据"按钮附近

#### 场景：切换到图表视图

- **当** 用户点击"图表展示"按钮
- **那么** 页面切换到图表视图模式
- **并且** 显示字段选择器和图表配置面板
- **并且** 隐藏数据表格

#### 场景：切换回表格视图

- **当** 用户在图表视图中点击"表格视图"按钮
- **那么** 页面切换回表格视图
- **并且** 显示数据表格
- **并且** 隐藏图表视图

---

### 需求：字段选择

系统必须允许用户选择用于图表展示的字段。

#### 场景：显示字段选择器

- **当** 用户进入图表视图
- **那么** 显示字段选择器组件
- **并且** 列出所有可用的字段（来自 `field_info`）
- **并且** 显示字段的中文名称和字段类型

#### 场景：选择 X 轴字段

- **当** 用户从字段选择器中选择一个字段作为 X 轴
- **那么** 该字段被标记为 X 轴字段
- **并且** 系统根据字段类型推荐合适的图表类型

#### 场景：选择 Y 轴字段（单个）

- **当** 用户从字段选择器中选择一个数值字段作为 Y 轴
- **那么** 该字段被标记为 Y 轴字段
- **并且** 图表显示单个数据系列

#### 场景：选择多个 Y 轴字段（多系列）

- **当** 用户从字段选择器中选择多个数值字段作为 Y 轴
- **那么** 这些字段都被标记为 Y 轴字段
- **并且** 每个 Y 轴字段作为一个数据系列显示
- **并且** 每个系列使用不同的颜色和图例标识

#### 场景：选择分类字段

- **当** 用户选择分类字段用于分组或图例
- **那么** 该字段被标记为分类字段
- **并且** 图表按该字段进行分组展示

#### 场景：字段类型识别

- **当** 系统显示字段列表
- **那么** 自动识别字段类型（数值、分类、时间）
- **并且** 在字段选择器中显示类型标识
- **并且** 基于字段类型提供图表类型建议

#### 场景：字段选择验证

- **当** 用户未选择必需的字段（如 Y 轴字段）
- **那么** 显示提示信息"请至少选择一个数值字段作为 Y 轴"
- **并且** 禁用图表生成按钮

---

### 需求：图表类型选择

系统必须支持用户选择图表类型。

#### 场景：显示图表类型选择器

- **当** 用户进入图表视图
- **那么** 显示图表类型选择器
- **并且** 提供以下选项：柱状图、折线图、饼图、散点图、条形图

#### 场景：智能推荐图表类型

- **当** 用户选择了字段
- **那么** 系统根据字段类型和数量推荐合适的图表类型
- **并且** 推荐的图表类型高亮显示

#### 场景：切换图表类型

- **当** 用户选择不同的图表类型
- **那么** 图表立即更新为新类型
- **并且** 如果新类型不兼容当前字段选择，显示提示信息

#### 场景：图表类型与字段兼容性检查

- **当** 用户选择饼图
- **那么** 要求至少有一个分类字段和一个数值字段
- **当** 用户选择散点图
- **那么** 要求至少有两个数值字段
- **当** 图表类型与字段不兼容
- **那么** 显示错误提示并阻止图表生成

---

### 需求：数据转换与图表渲染

系统必须将查询结果数据转换为图表格式并渲染。

#### 场景：转换表格数据为图表数据

- **当** 用户选择了字段和图表类型
- **那么** 系统将表格数据转换为 ECharts 所需格式
- **并且** 根据图表类型应用相应的转换逻辑

#### 场景：渲染柱状图（单系列）

- **当** 用户选择柱状图类型且只选择一个 Y 轴字段
- **那么** 系统生成柱状图配置
- **并且** X 轴显示分类字段值
- **并且** Y 轴显示数值字段值
- **并且** 图表正确渲染

#### 场景：渲染柱状图（多系列）

- **当** 用户选择柱状图类型且选择多个 Y 轴字段
- **那么** 系统生成多系列柱状图配置
- **并且** X 轴显示分类字段值
- **并且** Y 轴显示数值字段值
- **并且** 每个 Y 轴字段作为一个系列显示
- **并且** 不同系列使用不同颜色区分
- **并且** 图例显示所有系列名称

#### 场景：渲染折线图（单系列）

- **当** 用户选择折线图类型且只选择一个 Y 轴字段
- **那么** 系统生成折线图配置
- **并且** X 轴显示分类或时间字段值
- **并且** Y 轴显示数值字段值
- **并且** 图表正确渲染

#### 场景：渲染折线图（多系列）

- **当** 用户选择折线图类型且选择多个 Y 轴字段
- **那么** 系统生成多系列折线图配置
- **并且** X 轴显示分类或时间字段值
- **并且** Y 轴显示数值字段值
- **并且** 每个 Y 轴字段作为一条折线显示
- **并且** 不同折线使用不同颜色和样式区分

#### 场景：渲染饼图

- **当** 用户选择饼图类型
- **那么** 系统生成饼图配置
- **并且** 按分类字段分组
- **并且** 显示数值字段的占比
- **并且** 图表正确渲染

#### 场景：渲染散点图

- **当** 用户选择散点图类型
- **那么** 系统生成散点图配置
- **并且** X 轴和 Y 轴分别显示两个数值字段
- **并且** 图表正确渲染

#### 场景：渲染条形图

- **当** 用户选择条形图类型
- **那么** 系统生成条形图配置
- **并且** Y 轴显示分类字段值
- **并且** X 轴显示数值字段值
- **并且** 图表正确渲染

#### 场景：数据聚合

- **当** 用户选择分类字段进行分组
- **那么** 系统对数值字段进行聚合（求和、平均值、计数）
- **并且** 图表显示聚合后的数据

---

### 需求：图表配置

系统必须允许用户配置图表显示选项。

#### 场景：显示图表配置面板

- **当** 用户进入图表视图
- **那么** 显示图表配置面板（可折叠）
- **并且** 包含 X 轴、Y 轴、图例、标题等配置选项

#### 场景：配置 X 轴

- **当** 用户在配置面板中调整 X 轴设置
- **那么** 可以设置 X 轴标题
- **并且** 可以设置 X 轴标签旋转角度
- **并且** 图表立即更新

#### 场景：配置 Y 轴

- **当** 用户在配置面板中调整 Y 轴设置
- **那么** 可以设置 Y 轴标题
- **并且** 可以设置 Y 轴数值格式
- **并且** 图表立即更新

#### 场景：配置图例

- **当** 用户在配置面板中调整图例设置
- **那么** 可以显示或隐藏图例
- **并且** 可以设置图例位置
- **并且** 图表立即更新

#### 场景：配置标题

- **当** 用户在配置面板中输入图表标题
- **那么** 图表顶部显示自定义标题
- **并且** 标题支持中文

---

### 需求：大数据量处理

系统必须优雅处理大数据量的图表展示。

#### 场景：数据量限制提示

- **当** 查询结果数据行数超过 1000 行
- **那么** 显示提示信息"数据量较大，建议添加过滤条件或使用数据聚合"
- **并且** 图表自动采样或聚合数据（最多显示 1000 个数据点）

#### 场景：数据采样

- **当** 数据行数超过限制
- **那么** 系统自动采样数据（均匀采样）
- **并且** 在图表下方显示"已采样显示 1000/总数据量 条数据"

#### 场景：数据聚合建议

- **当** 数据量较大且用户选择了分类字段
- **那么** 系统建议用户使用数据聚合功能
- **并且** 提供"按分类字段聚合"快捷按钮

---

### 需求：图表视图状态保持

系统必须在视图切换时保持查询状态。

#### 场景：保持查询结果

- **当** 用户在表格视图和图表视图之间切换
- **那么** 查询结果数据保持不变
- **并且** 查询条件保持不变

#### 场景：保持图表配置

- **当** 用户从图表视图切换回表格视图
- **那么** 图表配置（字段选择、图表类型等）暂时保存
- **并且** 再次切换到图表视图时恢复配置

#### 场景：查询后重置图表

- **当** 用户修改查询条件并重新查询
- **那么** 如果当前在图表视图，图表自动更新为新数据
- **并且** 如果图表配置与新数据不兼容，显示提示并重置配置

---

### 需求：图表加载和错误处理

系统必须在图表生成过程中显示适当的加载状态和错误提示。

#### 场景：显示加载状态

- **当** 系统正在转换数据和生成图表
- **那么** 显示加载动画或骨架屏
- **并且** 禁用图表配置操作

#### 场景：空数据提示

- **当** 查询结果为空
- **那么** 图表视图显示空状态提示"暂无数据，请先执行查询"
- **并且** 不显示图表

#### 场景：字段选择错误提示

- **当** 用户选择的字段不满足图表类型要求
- **那么** 显示错误提示信息
- **并且** 说明需要选择哪些字段

#### 场景：数据转换错误处理

- **当** 数据转换过程中发生错误
- **那么** 显示友好的错误提示
- **并且** 记录错误日志
- **并且** 允许用户重新配置

---

### 需求：响应式布局

系统必须确保图表在不同屏幕尺寸下正常显示。

#### 场景：图表自适应宽度

- **当** 浏览器窗口大小改变
- **那么** 图表自动调整大小以适应容器
- **并且** 保持图表比例和可读性

#### 场景：移动端适配

- **当** 用户在移动设备上查看图表
- **那么** 图表配置面板可折叠或收起
- **并且** 图表在小屏幕上仍然可读

---

### 需求：图表 PNG 导出

系统必须支持将图表导出为 PNG 图片格式。

#### 场景：显示导出按钮

- **当** 用户在图表视图中查看图表
- **那么** 在图表工具栏中显示"导出 PNG"按钮

#### 场景：导出图表为 PNG

- **当** 用户点击"导出 PNG"按钮
- **那么** 系统调用 ECharts 的 `getDataURL` API 生成图片数据
- **并且** 创建下载链接
- **并且** 触发浏览器下载 PNG 文件
- **并且** 文件名包含主表名和时间戳（如：`联合查询_用户表_2026-01-20.png`）

#### 场景：导出图片质量

- **当** 用户导出图表
- **那么** 使用高分辨率导出（pixelRatio: 2）
- **并且** 导出的图片清晰可读

#### 场景：导出进度提示

- **当** 用户点击导出按钮
- **那么** 显示"正在导出..."提示
- **并且** 导出完成后显示成功提示

---

### 需求：图表配置保存和加载

系统必须允许用户保存和加载图表配置。

#### 场景：显示配置管理按钮

- **当** 用户在图表视图中
- **那么** 显示"保存配置"和"加载配置"按钮

#### 场景：保存图表配置

- **当** 用户点击"保存配置"按钮
- **那么** 弹出输入对话框
- **并且** 用户输入配置名称
- **并且** 系统保存以下配置信息：
  - 图表类型
  - X 轴字段
  - Y 轴字段（多个）
  - 分类字段（如有）
  - 图表配置选项（标题、图例等）
- **并且** 配置保存到 localStorage（键名：`join-query-chart-configs`）
- **并且** 保存成功后显示提示

#### 场景：加载图表配置

- **当** 用户点击"加载配置"按钮
- **那么** 显示已保存的配置列表
- **并且** 列表显示配置名称和创建时间
- **并且** 用户可以选择一个配置

#### 场景：应用已保存的配置

- **当** 用户选择一个已保存的配置
- **那么** 系统自动应用该配置：
  - 设置图表类型
  - 选择 X 轴字段
  - 选择 Y 轴字段（多个）
  - 设置分类字段（如有）
  - 应用图表配置选项
- **并且** 图表立即更新为新配置
- **并且** 如果配置中的字段在当前查询结果中不存在，显示提示

#### 场景：删除已保存的配置

- **当** 用户在配置列表中点击删除按钮
- **那么** 弹出确认对话框
- **并且** 确认后删除该配置
- **并且** 从 localStorage 中移除配置数据

#### 场景：配置列表为空

- **当** 用户点击"加载配置"但无已保存配置
- **那么** 显示空状态提示"暂无保存的配置"

#### 场景：配置与查询配置分离

- **当** 系统保存或加载图表配置
- **那么** 图表配置与查询配置（主表、关联表等）分开存储
- **并且** 图表配置独立管理，不影响查询配置

---

### 需求：多系列图表支持

系统必须支持选择多个 Y 轴字段，创建多系列图表。

#### 场景：选择多个 Y 轴字段

- **当** 用户在字段选择器中选择多个数值字段作为 Y 轴
- **那么** 所有选中的字段都被标记为 Y 轴字段
- **并且** 字段选择器显示已选择的字段数量（如：已选择 3 个 Y 轴字段）

#### 场景：多系列图表渲染

- **当** 用户选择了多个 Y 轴字段并生成图表
- **那么** 系统为每个 Y 轴字段生成一个数据系列
- **并且** 每个系列使用不同的颜色
- **并且** 图例显示所有系列的名称（使用字段的中文名称或字段名）

#### 场景：多系列柱状图

- **当** 用户选择柱状图类型且选择了多个 Y 轴字段
- **那么** 图表显示多个系列的柱状图
- **并且** 同一 X 轴值下，不同系列的柱子并排显示
- **并且** 不同系列使用不同颜色区分

#### 场景：多系列折线图

- **当** 用户选择折线图类型且选择了多个 Y 轴字段
- **那么** 图表显示多条折线
- **并且** 每条折线代表一个 Y 轴字段
- **并且** 不同折线使用不同颜色和线型区分

#### 场景：多系列组合图表

- **当** 用户选择了多个 Y 轴字段
- **那么** 系统支持为不同系列设置不同的图表类型（如：系列1使用柱状图，系列2使用折线图）
- **并且** 图表正确渲染组合类型

#### 场景：多系列图例交互

- **当** 图表显示多个系列
- **那么** 图例支持点击切换系列显示/隐藏
- **并且** 点击图例项后，对应的系列在图表中显示或隐藏

#### 场景：多系列数据提示

- **当** 用户悬停在图表上
- **那么** Tooltip 显示所有系列在该点的数值
- **并且** 不同系列的数据清晰区分
