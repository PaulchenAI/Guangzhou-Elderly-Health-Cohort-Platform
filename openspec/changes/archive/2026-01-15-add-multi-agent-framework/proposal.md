# 变更：添加多智能体AI框架

## 为什么

项目需要一个强大的AI能力层，用于代码分析、智能生成、知识检索等场景。采用**Claude Code CLI作为核心引擎**，结合LangChain + LangGraph进行多智能体编排，可以实现：
- 本地文件操作和代码处理（通过Claude Code CLI）
- 智能代码分析和生成
- 基于RAG的知识检索增强
- 多智能体协作完成复杂任务
- 可配置的Prompts和工作流

## 变更内容

### 新增功能

1. **Claude Code CLI核心引擎**
   - **本地文件操作**：读取、写入、编辑、搜索、删除文件
   - **Coding能力**：代码分析、生成、重构、Bug修复、代码审查
   - **上下文理解**：项目结构分析、依赖分析、语义搜索
   - 子进程封装、并发控制、超时处理

2. **多智能体编排架构**（LangChain + LangGraph）
   - Orchestrator Agent（编排智能体）：任务分解、智能体调度、结果汇总
   - RAG Agent（检索智能体）：知识库检索、上下文增强
   - Memory Agent（记忆智能体）：对话历史、长期记忆管理
   - Planning Agent（规划智能体）：★ 集成OpenSpec，将复杂任务拆解为多个变更提案并管理

3. **RAG检索增强**
   - 代码库向量索引和语义检索
   - 业务文档知识库
   - 数据库元数据检索
   - 用户上传文档支持

4. **上下文记忆系统**
   - 短期对话记忆（会话级）
   - 长期知识记忆（持久化）
   - 会话状态管理
   - 记忆检索和更新

5. **日志记录系统**
   - 智能体交互日志
   - Claude Code CLI调用追踪
   - 性能监控指标
   - 错误和异常追踪

6. **环境变量配置（.env）**
   - Claude Code CLI路径和参数配置
   - LLM API密钥配置
   - 向量数据库连接配置
   - Redis连接配置（记忆缓存）
   - 日志级别和输出配置

7. **OpenSpec集成**
   - 任务拆解为多个OpenSpec变更提案
   - 自动创建、验证、管理OpenSpec提案
   - 提案依赖关系分析
   - 提案执行计划生成
   - 提案进度跟踪和归档

8. **YAML配置系统**
   - Prompts模板配置
   - 智能体行为配置
   - 工作流定义配置
   - 模型参数配置

## 影响

- 受影响规范：无（新增功能）
- 受影响代码：
  - 新增顶层目录 `AIagent/`
  - 可能与 `backend-django/` 集成（API暴露）
- 新增依赖：
  - langchain
  - langgraph
  - chromadb（向量数据库）
  - pyyaml
  - python-dotenv
  - 其他LangChain生态依赖
- **前置条件**：
  - Claude Code CLI已安装并可用
  - openspec-cn CLI已安装并可用（用于OpenSpec集成）

## 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| Claude Code CLI不可用 | 高 | 启动时检查，给出明确错误提示 |
| Claude Code CLI执行超时 | 中 | 可配置超时，支持取消操作 |
| 并发调用资源竞争 | 中 | 信号量控制并发数 |
| 向量数据库性能 | 中 | 支持多种后端，可切换 |
| 内存占用 | 中 | 配置化记忆限制，LRU淘汰 |
