# 变更：添加外键联合查询 API

## 为什么

目前系统已实现单表查询和外键关系元数据查询功能，但无法根据外键关系自动进行多表联合查询。用户需要一个能够根据外键关系自动关联多表数据的功能，以便更方便地查看关联数据，减少手动编写复杂 SQL 的需求。

## 变更内容

- 新增联合查询 API，支持指定主表并根据外键关系自动 JOIN 关联表
- 支持多级关联查询（如 A → B → C）
- 使用 LEFT JOIN 确保主表数据完整性
- 自动处理字段名冲突（添加表名前缀）
- 支持分页、过滤、排序功能
- 支持配置关联深度限制
- 支持数据导出功能

## 影响

- 受影响规范：新增 `join-query-api` 功能规范
- 受影响代码：
  - `backend-django/core/table_query/` - 扩展表查询模块
  - `backend-django/core/foreignkey/` - 复用外键元数据
