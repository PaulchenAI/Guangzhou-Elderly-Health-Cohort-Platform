## 新增需求

### 需求：外键关系元数据 API

系统必须提供 RESTful API 查询外键关系元数据，支持 AI 通过表名查询表之间的关联关系。

#### 场景：获取外键关系列表（分页）

- **当** 调用 `GET /foreignkey/metadata` 接口
- **那么** 返回外键关系分页列表
- **并且** 支持按源表名、目标表名过滤
- **并且** 返回总数、当前页、每页数量

#### 场景：获取所有外键关系

- **当** 调用 `GET /foreignkey/metadata/all` 接口
- **那么** 返回所有外键关系（不分页）
- **并且** 可通过 `source_table` 或 `target_table` 参数过滤

#### 场景：获取单个外键详情

- **当** 调用 `GET /foreignkey/metadata/{id}` 接口
- **那么** 返回指定 ID 的外键关系详情
- **并且** 包含源表、源字段、目标表、目标字段、约束名、删除规则等信息

---

### 需求：AI 友好的表名查询 API

系统必须提供支持模糊匹配的表名查询 API，便于 AI 通过自然语言提取的表名查询外键关系。

#### 场景：按源表名查询外键（出向引用）

- **当** 调用 `GET /foreignkey/by-source/{table_name}` 接口
- **那么** 返回指定表作为源表的所有外键关系
- **并且** 支持精确匹配和模糊匹配
- **并且** 支持带前缀或不带前缀的表名
- **例如** `/foreignkey/by-source/BS_STAFF` 匹配 `gzlry_BS_STAFF`

#### 场景：按目标表名查询外键（入向引用）

- **当** 调用 `GET /foreignkey/by-target/{table_name}` 接口
- **那么** 返回指定表作为目标表的所有外键关系（被引用）
- **并且** 支持精确匹配和模糊匹配
- **并且** 支持带前缀或不带前缀的表名
- **例如** `/foreignkey/by-target/BS_DEPARTMENT` 返回所有引用该表的外键

#### 场景：获取表的所有关联关系

- **当** 调用 `GET /foreignkey/relations/{table_name}` 接口
- **那么** 返回指定表的所有外键关系
- **并且** 包含出向关系（该表引用的其他表）
- **并且** 包含入向关系（引用该表的其他表）
- **并且** 返回出向和入向的数量统计

---

### 需求：外键统计信息 API

系统必须提供外键关系的统计信息接口。

#### 场景：获取外键统计信息

- **当** 调用 `GET /foreignkey/stats` 接口
- **那么** 返回以下统计信息：
  - 总外键关系数
  - 有外键的表数（源表去重）
  - 被引用的表数（目标表去重）

---

### 需求：OpenAPI 文档规范

所有外键 API 端点必须提供规范化的 OpenAPI 描述，支持 AI 意图理解。

#### 场景：API Summary 规范

- **当** 定义 API 端点
- **那么** 必须提供中文 summary
- **并且** 格式为"动词 + 名词（补充说明）"
- **例如** `summary="获取外键关系列表（分页）"`

#### 场景：API Description 规范

- **当** 定义 API 端点
- **那么** 必须提供详细的中文 description
- **并且** 说明查询参数、返回值、AI 调用建议
- **例如** `AI 调用建议: 直接传入用户提到的表名，支持不带前缀。`
