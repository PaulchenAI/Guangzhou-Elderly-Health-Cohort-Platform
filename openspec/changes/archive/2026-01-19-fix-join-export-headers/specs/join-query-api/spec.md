## 修改需求

### 需求：联合查询导出

系统必须支持将联合查询结果导出为文件。

#### 场景：导出联合查询结果

- **当** 调用 `POST /api/core/table-query/join-export` 接口
- **那么** 系统执行联合查询并导出结果
- **并且** 支持 Excel 和 CSV 格式

#### 场景：导出字段表头

- **当** 导出联合查询结果
- **那么** 表头使用与前端表单一致的格式
- **并且** 如果字段有中文注释（`field_comment`），表头格式为 `中文名/字段名 (表名)`
- **并且** 如果字段没有中文注释，表头格式为 `字段名 (表名)`
- **并且** 表头不再直接使用数据库列名（英文别名）

#### 场景：导出行数限制

- **当** 导出数据
- **那么** 默认最大导出行数为 10000
- **并且** 可通过 `max_rows` 参数调整，上限 100000
