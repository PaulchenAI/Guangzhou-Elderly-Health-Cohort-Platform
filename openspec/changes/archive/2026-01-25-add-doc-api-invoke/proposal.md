# 变更：添加 HIS 接口在线调用功能

## 为什么

当前文档 API 前端只能浏览接口定义信息，无法实际调用 HIS 接口测试数据。用户需要：
1. 在前端直接调用 HIS 真实接口，获取实际返回数据
2. 查看接口的访问状态（可访问/不可访问）
3. 保存调用历史，方便追溯和复用

## 变更内容

### 后端变更
- 新增 HIS 接口代理服务，转发请求到真实 HIS API
- 新增调用历史模型（MySQL 持久化）
- 新增调用历史查询 API
- 接口列表返回访问状态字段

### 前端变更
- 接口列表增加"访问状态"列（可访问/不可访问标签）
- 新增接口调用面板：
  - 请求参数表单（用户可编辑）
  - 默认测试参数填充
  - 发送请求按钮
  - 响应数据表格展示
- 新增调用历史查看功能

## 影响

- 受影响规范：
  - `doc-api` - 后端新增代理调用和历史查询 API
  - `doc-api-frontend` - 前端新增调用面板和状态标记
- 受影响代码：
  - `backend-django/core/doc_api/` - 服务层和 API 扩展
  - `web/apps/web-ele/src/views/doc-api/` - 前端组件扩展
  - 数据库迁移（新增调用历史表）
