# 变更：为动态查询接口添加字段级权限控制

## 为什么

当前动态查询接口的 `searchable-fields` 返回静态配置的字段列表，所有用户看到相同的可搜索字段。这导致：
1. 敏感字段（如手机号、邮箱）对所有调用者可见
2. 无法根据用户角色控制数据访问范围
3. AI Agent 可能构造出超出用户权限的查询条件

## 变更内容

- **通过系统权限表控制字段访问**，不修改字段配置结构
- 使用权限编码命名规范 `{module}:query:{field_name}` 标识字段权限
- 修改 `searchable-fields` 接口，查询权限表过滤用户无权限的字段
- 修改 `query` 接口，验证用户是否有权限使用查询中的字段
- 在权限表中添加敏感字段的权限记录

## 影响

- 受影响规范：`backend-api`
- 受影响代码：
  - `common/fu_crud.py` - 添加权限检查函数
  - 所有模块的 `*_api.py` - 接口传入模块名和用户权限
- 权限表新增记录

## 向后兼容性

- 字段配置结构不变
- `searchable-fields` 接口输出结构不变
- 权限表中无对应记录的字段，行为与现有一致（所有人可见）
