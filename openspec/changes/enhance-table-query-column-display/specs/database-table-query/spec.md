## 修改需求

### 需求：前端查询页面

系统必须提供前端页面支持表切换和数据展示。

#### 场景：表选择器

- **当** 用户访问表查询页面
- **那么** 左侧显示可查询表的列表
- **并且** 支持按配置中的显示名称展示

#### 场景：动态表格

- **当** 用户选择某个表配置
- **那么** 表格列根据配置动态生成
- **并且** 支持分页、排序功能
- **并且** 表格列标题同时显示字段的中文名称（`displayName`）和原始字段名（`name`）
- **并且** 列标题显示格式为：`中文名称 (字段名)`，如果中文名称与字段名相同或为空，则只显示字段名

#### 场景：动态搜索表单

- **当** 表配置包含可搜索字段
- **那么** 搜索表单动态生成对应的输入控件
- **并且** 根据字段类型选择合适的组件
- **并且** 搜索表单标签显示字段的中文名称（`displayName`）
