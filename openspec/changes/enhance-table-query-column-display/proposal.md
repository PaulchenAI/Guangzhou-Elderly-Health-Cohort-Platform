# 变更：增强表数据查询前端列显示

## 为什么

当前表数据查询前端页面在显示表格列时，只显示字段的中文名称（`displayName`，来自数据库 COMMENT 或配置文件），不显示字段的原始名称（`name`）。这导致：
1. 用户无法同时看到字段的中文注释和原始字段名
2. 在需要引用字段名进行技术操作时，需要额外查找
3. 信息展示不够完整，影响用户体验

## 变更内容

- **修改需求**：前端表格列标题同时显示字段的中文名称（comment）和原始字段名
- **修改需求**：优化列标题显示格式，使信息更清晰易读

## 影响

- **受影响规范**：`database-table-query` - 前端查询页面
- **受影响代码**：
  - `web/apps/web-ele/src/views/table-query/data.ts` - 列配置构建逻辑
  - `web/apps/web-ele/src/views/table-query/index.vue` - 表格显示组件
