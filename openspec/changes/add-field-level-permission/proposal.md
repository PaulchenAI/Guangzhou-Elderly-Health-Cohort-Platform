# 变更：为动态查询接口添加字段级权限控制

## 为什么

当前动态查询接口的 `searchable-fields` 返回静态配置的字段列表，所有用户看到相同的可搜索字段。这导致：
1. 敏感字段（如手机号、邮箱）对所有调用者可见
2. 无法根据用户角色控制数据访问范围
3. AI Agent 可能构造出超出用户权限的查询条件

## 变更内容

- 在可搜索字段配置中添加 `permission` 属性，指定访问该字段所需的权限
- 修改 `get_searchable_fields_response` 函数，根据当前用户权限过滤可见字段
- 修改 `dynamic_query` 函数，验证用户是否有权限使用查询中的字段
- 为核心模块的敏感字段添加权限配置

## 影响

- 受影响规范：`backend-api`
- 受影响代码：
  - `common/fu_schema.py` - 字段配置结构
  - `common/fu_crud.py` - 查询函数权限验证
  - 所有模块的 `*_schema.py` - 字段权限配置
  - 所有模块的 `*_api.py` - 接口传入用户权限

## 向后兼容性

- 字段配置的 `permission` 属性为可选，默认 `None` 表示无需权限
- 现有不带权限配置的字段行为不变
