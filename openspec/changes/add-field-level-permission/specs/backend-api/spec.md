# 后端 API 规范增量

## 新增需求

### 需求：动态查询字段级权限控制

系统必须支持为可搜索字段配置访问权限，并在查询时验证用户是否具有相应权限。

#### 场景：无权限用户获取可搜索字段列表

- **当** 用户调用 `GET /{module}/searchable-fields` 接口
- **并且** 用户不具有某些字段的访问权限
- **那么** 返回的字段列表应排除该用户无权限的字段

#### 场景：无权限用户尝试使用受保护字段查询

- **当** 用户调用 `POST /{module}/query` 接口
- **并且** 查询条件中包含用户无权限的字段
- **那么** 系统应返回 403 错误
- **并且** 错误信息应包含缺少的权限编码

#### 场景：有权限用户正常查询

- **当** 用户调用 `POST /{module}/query` 接口
- **并且** 用户具有查询条件中所有字段的访问权限
- **那么** 查询应正常执行并返回结果

#### 场景：字段无权限配置时默认可访问

- **当** 可搜索字段配置中未设置 `permission` 属性
- **那么** 该字段对所有已认证用户可见
- **并且** 查询时不进行权限验证

### 需求：用户敏感字段权限

用户模块的敏感字段（手机号、邮箱）必须受 `user:view_sensitive` 权限保护。

#### 场景：管理员可见用户敏感字段

- **当** 具有 `user:view_sensitive` 权限的用户调用 `GET /user/searchable-fields`
- **那么** 返回的字段列表应包含 `mobile` 和 `email` 字段

#### 场景：普通用户不可见用户敏感字段

- **当** 不具有 `user:view_sensitive` 权限的用户调用 `GET /user/searchable-fields`
- **那么** 返回的字段列表不应包含 `mobile` 和 `email` 字段

### 需求：登录日志 IP 字段权限

登录日志模块的 IP 字段必须受 `login_log:view_ip` 权限保护。

#### 场景：安全管理员可见登录 IP

- **当** 具有 `login_log:view_ip` 权限的用户调用 `GET /login-log/searchable-fields`
- **那么** 返回的字段列表应包含 `login_ip` 字段

#### 场景：普通用户不可见登录 IP

- **当** 不具有 `login_log:view_ip` 权限的用户调用 `GET /login-log/searchable-fields`
- **那么** 返回的字段列表不应包含 `login_ip` 字段
