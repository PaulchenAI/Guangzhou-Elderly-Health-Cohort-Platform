## 需求
### 需求：联合查询页面入口

系统必须提供联合查询页面，与单表查询页面并列。

#### 场景：导航到联合查询页面

- **当** 用户点击导航菜单中的"联合查询"
- **那么** 系统显示联合查询页面
- **并且** 页面包含主表选择、关联配置、数据展示三个区域

#### 场景：页面布局

- **当** 用户访问联合查询页面
- **那么** 左侧显示主表选择器（宽度约 240px）
- **并且** 中间显示关联配置面板（宽度约 288px）
- **并且** 右侧显示数据结果区域（自适应宽度）

---

### 需求：主表选择

系统必须允许用户从可用表列表中选择主表。

#### 场景：显示表列表

- **当** 页面加载完成
- **那么** 左侧显示所有可用的表配置列表
- **并且** 显示表的显示名称和表名
- **并且** 支持搜索过滤

#### 场景：选择主表

- **当** 用户点击某个表
- **那么** 该表被标记为选中状态
- **并且** 系统自动加载该表的关联关系

#### 场景：搜索表

- **当** 用户在搜索框输入关键词
- **那么** 表列表实时过滤
- **并且** 匹配表名或显示名称

---

### 需求：关联关系展示

系统必须以树形结构展示主表的关联关系。

#### 场景：加载关联关系

- **当** 用户选择主表
- **那么** 系统调用 `join-preview` API 获取关联关系
- **并且** 显示加载状态
- **并且** 加载完成后显示关联关系树

#### 场景：展示关联关系树

- **当** 关联关系加载完成
- **那么** 以树形结构展示关联表
- **并且** 每个节点显示表名和关联深度
- **并且** 默认展开第一级关联

#### 场景：显示关联详情

- **当** 用户悬停在关联表节点
- **那么** 显示关联详情 Tooltip
- **并且** 包含：来源表、外键字段、目标字段

#### 场景：无关联关系

- **当** 主表没有外键关联
- **那么** 显示空状态提示"该表无外键关联"
- **并且** 建议用户选择其他表或使用单表查询

---

### 需求：关联表选择

系统必须允许用户选择要包含在联合查询中的关联表。

#### 场景：勾选关联表

- **当** 用户勾选关联关系树中的某个节点
- **那么** 该表被标记为要关联的表
- **并且** 勾选状态在界面上可见

#### 场景：取消勾选

- **当** 用户取消勾选某个关联表节点
- **那么** 该表从要关联的列表中移除

#### 场景：勾选父级自动勾选子级

- **当** 用户勾选某个有子节点的关联表
- **那么** 该表及其所有子关联表都被勾选

#### 场景：部分勾选状态

- **当** 某个父级节点的子节点部分被勾选
- **那么** 父级节点显示半选状态

---

### 需求：关联深度设置

系统必须允许用户设置最大关联深度。

#### 场景：默认深度

- **当** 页面加载完成
- **那么** 关联深度默认为 2

#### 场景：调整深度

- **当** 用户调整深度滑块
- **那么** 深度值更新（范围 1-5）
- **并且** 关联关系树根据新深度重新加载

#### 场景：深度限制

- **当** 用户设置深度为 5（最大值）
- **那么** 滑块不能再增加
- **并且** 显示提示"已达最大深度"

---

### 需求：执行联合查询

系统必须允许用户执行联合查询并展示结果。

#### 场景：触发查询

- **当** 用户点击"执行查询"按钮
- **那么** 系统构建查询参数
- **并且** 调用 `join-query` API
- **并且** 显示加载状态

#### 场景：查询参数

- **当** 执行查询
- **那么** 参数包含：主表名、选中的关联表列表、关联深度
- **并且** 分页参数（默认 page=1, pageSize=20）

#### 场景：展示查询结果

- **当** 查询成功返回
- **那么** 在表格中展示数据
- **并且** 列标题使用 `表名_字段名` 格式
- **并且** 显示关联信息摘要（关联了哪些表、共多少条数据）

#### 场景：查询失败

- **当** 查询发生错误
- **那么** 显示错误提示消息
- **并且** 保留之前的查询结果（如有）

---

### 需求：数据分页

系统必须支持查询结果的分页展示。

#### 场景：分页控件

- **当** 查询结果展示
- **那么** 表格底部显示分页控件
- **并且** 显示总记录数、当前页码、每页数量

#### 场景：切换页码

- **当** 用户点击分页控件切换页码
- **那么** 系统使用新页码重新查询
- **并且** 表格数据更新

#### 场景：调整每页数量

- **当** 用户更改每页数量
- **那么** 系统使用新的 pageSize 重新查询
- **并且** 页码重置为 1

---

### 需求：数据过滤

系统必须支持对查询结果进行过滤。

#### 场景：显示过滤表单

- **当** 查询结果展示
- **那么** 表格上方显示过滤条件区域

#### 场景：添加过滤条件

- **当** 用户输入过滤条件
- **那么** 条件字段使用 `表名_字段名` 格式
- **并且** 支持模糊匹配（like）

#### 场景：执行过滤

- **当** 用户点击"查询"按钮
- **那么** 系统使用过滤条件重新查询
- **并且** 页码重置为 1

#### 场景：重置过滤

- **当** 用户点击"重置"按钮
- **那么** 清空所有过滤条件
- **并且** 重新执行无条件查询

---

### 需求：数据排序

系统必须支持对查询结果进行排序。

#### 场景：点击列头排序

- **当** 用户点击表格列头
- **那么** 按该列升序排序
- **并且** 列头显示排序图标

#### 场景：切换排序方向

- **当** 用户再次点击已排序的列头
- **那么** 切换为降序排序

#### 场景：取消排序

- **当** 用户第三次点击已排序的列头
- **那么** 取消该列排序
- **并且** 恢复默认排序

---

### 需求：列显示控制

系统必须允许用户控制表格列的显示/隐藏。

#### 场景：打开列选择器

- **当** 用户点击"列设置"按钮
- **那么** 打开列选择器抽屉
- **并且** 按表分组展示所有列

#### 场景：隐藏列

- **当** 用户取消勾选某列
- **那么** 该列从表格中隐藏
- **并且** 勾选状态实时保存

#### 场景：显示列

- **当** 用户勾选某个已隐藏的列
- **那么** 该列在表格中显示

#### 场景：按表操作

- **当** 用户点击表名旁的"全选"按钮
- **那么** 该表的所有列都被选中
- **当** 用户点击"取消全选"
- **那么** 该表的所有列都被隐藏

#### 场景：记住列偏好

- **当** 用户调整列显示设置
- **那么** 设置保存到 localStorage
- **并且** 下次访问时自动应用

---

### 需求：数据导出

系统必须支持导出联合查询结果。

#### 场景：导出入口

- **当** 查询结果展示
- **那么** 显示"导出"下拉按钮
- **并且** 提供 Excel 和 CSV 两种格式选项

#### 场景：导出 Excel

- **当** 用户选择"导出 Excel"
- **那么** 系统调用 `join-export` API
- **并且** 下载 .xlsx 文件
- **并且** 文件名包含主表名和时间戳

#### 场景：导出 CSV

- **当** 用户选择"导出 CSV"
- **那么** 系统调用 `join-export` API
- **并且** 下载 .csv 文件

#### 场景：导出进度

- **当** 导出数据量较大
- **那么** 显示导出进度提示
- **并且** 支持取消导出

---

### 需求：查询配置保存

系统必须允许用户保存常用的联合查询配置。

#### 场景：保存配置

- **当** 用户点击"保存配置"按钮
- **那么** 弹出输入对话框
- **并且** 用户输入配置名称后保存
- **并且** 配置存储到 localStorage

#### 场景：配置内容

- **当** 保存配置
- **那么** 配置包含：
  - 主表名
  - 选中的关联表列表
  - 关联深度
  - 可见列设置（可选）

#### 场景：加载配置

- **当** 用户点击"加载配置"按钮
- **那么** 显示已保存的配置列表
- **并且** 用户选择后自动应用配置

#### 场景：应用配置

- **当** 用户选择一个已保存的配置
- **那么** 主表自动选中
- **并且** 关联表自动勾选
- **并且** 深度自动设置
- **并且** 自动执行查询

#### 场景：删除配置

- **当** 用户在配置列表中点击删除按钮
- **那么** 弹出确认对话框
- **并且** 确认后删除该配置

#### 场景：配置列表为空

- **当** 用户点击"加载配置"但无已保存配置
- **那么** 显示空状态提示"暂无保存的配置"

---

### 需求：加载状态

系统必须在各种操作时显示适当的加载状态。

#### 场景：加载关联关系

- **当** 正在加载关联关系
- **那么** 关联配置面板显示骨架屏

#### 场景：执行查询

- **当** 正在执行查询
- **那么** 数据区域显示加载遮罩
- **并且** "执行查询"按钮显示加载状态

#### 场景：导出数据

- **当** 正在导出数据
- **那么** 显示全局加载提示

---

### 需求：错误处理

系统必须对各种错误情况提供友好的提示。

#### 场景：API 调用失败

- **当** API 调用返回错误
- **那么** 显示错误消息通知
- **并且** 消息内容友好易懂

#### 场景：关联表数量过多

- **当** 选择的关联表超过 10 个
- **那么** 显示警告提示"关联表数量过多，可能影响查询性能"
- **并且** 仍然允许执行查询

#### 场景：查询超时

- **当** 查询执行超时
- **那么** 显示超时错误提示
- **并且** 建议减少关联表或添加过滤条件

---

### 需求：字段中文名称显示

系统必须在表头和搜索表单中显示字段的中文名称。

#### 场景：表头显示双语

- **当** 查询结果展示
- **那么** 表格列标题显示格式为 `中文名/英文名 (表名)`
- **并且** 如果字段没有中文注释，则只显示英文名

#### 场景：搜索表单显示中文

- **当** 显示搜索过滤表单
- **那么** 字段标签优先显示中文名称
- **并且** 如果字段没有中文注释，则显示英文名

---

### 需求：关联表中文名称显示

系统必须在关联关系树中显示表的中文名称。

#### 场景：关联树节点显示中文

- **当** 关联关系加载完成
- **那么** 树节点显示表的中文显示名称
- **并且** 如果表没有配置显示名称，则显示表名

---

### 需求：不存在表的健壮处理

系统必须优雅处理外键引用不存在表的情况。

#### 场景：跳过不存在的关联表

- **当** 外键元数据引用的表在数据库中不存在
- **那么** 系统自动跳过该关联表
- **并且** 关联关系树中不显示该表
- **并且** 不影响其他正常关联表的查询

### 需求：图表展示功能入口

系统必须在联合查询结果页面提供图表展示功能入口。

#### 场景：显示图表按钮

- **当** 用户执行联合查询并获得结果
- **那么** 在工具栏中显示"图表展示"按钮
- **并且** 按钮位于"导出数据"按钮附近

#### 场景：切换到图表视图

- **当** 用户点击"图表展示"按钮
- **那么** 页面切换到图表视图模式
- **并且** 显示字段选择器和图表配置面板
- **并且** 隐藏数据表格

#### 场景：切换回表格视图

- **当** 用户在图表视图中点击"表格视图"按钮
- **那么** 页面切换回表格视图
- **并且** 显示数据表格
- **并且** 隐藏图表视图

---

### 需求：字段选择

系统必须允许用户选择用于图表展示的字段。

#### 场景：显示字段选择器

- **当** 用户进入图表视图
- **那么** 显示字段选择器组件
- **并且** 列出所有可用的字段（来自 `field_info`）
- **并且** 显示字段的中文名称和字段类型

#### 场景：选择 X 轴字段

- **当** 用户从字段选择器中选择一个字段作为 X 轴
- **那么** 该字段被标记为 X 轴字段
- **并且** 系统根据字段类型推荐合适的图表类型

#### 场景：选择 Y 轴字段（单个）

- **当** 用户从字段选择器中选择一个数值字段作为 Y 轴
- **那么** 该字段被标记为 Y 轴字段
- **并且** 图表显示单个数据系列

#### 场景：选择多个 Y 轴字段（多系列）

- **当** 用户从字段选择器中选择多个数值字段作为 Y 轴
- **那么** 这些字段都被标记为 Y 轴字段
- **并且** 每个 Y 轴字段作为一个数据系列显示
- **并且** 每个系列使用不同的颜色和图例标识

#### 场景：选择分类字段

- **当** 用户选择分类字段用于分组或图例
- **那么** 该字段被标记为分类字段
- **并且** 图表按该字段进行分组展示

#### 场景：字段类型识别

- **当** 系统显示字段列表
- **那么** 自动识别字段类型（数值、分类、时间）
- **并且** 在字段选择器中显示类型标识
- **并且** 基于字段类型提供图表类型建议

#### 场景：字段选择验证

- **当** 用户未选择必需的字段（如 Y 轴字段）
- **那么** 显示提示信息"请至少选择一个数值字段作为 Y 轴"
- **并且** 禁用图表生成按钮

---

### 需求：图表类型选择

系统必须支持用户选择图表类型。

#### 场景：显示图表类型选择器

- **当** 用户进入图表视图
- **那么** 显示图表类型选择器
- **并且** 提供以下选项：柱状图、折线图、饼图、散点图、条形图

#### 场景：智能推荐图表类型

- **当** 用户选择了字段
- **那么** 系统根据字段类型和数量推荐合适的图表类型
- **并且** 推荐的图表类型高亮显示

#### 场景：切换图表类型

- **当** 用户选择不同的图表类型
- **那么** 图表立即更新为新类型
- **并且** 如果新类型不兼容当前字段选择，显示提示信息

#### 场景：图表类型与字段兼容性检查

- **当** 用户选择饼图
- **那么** 要求至少有一个分类字段和一个数值字段
- **当** 用户选择散点图
- **那么** 要求至少有两个数值字段
- **当** 图表类型与字段不兼容
- **那么** 显示错误提示并阻止图表生成

---

### 需求：数据转换与图表渲染

系统必须将查询结果数据转换为图表格式并渲染。

#### 场景：转换表格数据为图表数据

- **当** 用户选择了字段和图表类型
- **那么** 系统将表格数据转换为 ECharts 所需格式
- **并且** 根据图表类型应用相应的转换逻辑

#### 场景：渲染柱状图（单系列）

- **当** 用户选择柱状图类型且只选择一个 Y 轴字段
- **那么** 系统生成柱状图配置
- **并且** X 轴显示分类字段值
- **并且** Y 轴显示数值字段值
- **并且** 图表正确渲染

#### 场景：渲染柱状图（多系列）

- **当** 用户选择柱状图类型且选择多个 Y 轴字段
- **那么** 系统生成多系列柱状图配置
- **并且** X 轴显示分类字段值
- **并且** Y 轴显示数值字段值
- **并且** 每个 Y 轴字段作为一个系列显示
- **并且** 不同系列使用不同颜色区分
- **并且** 图例显示所有系列名称

#### 场景：渲染折线图（单系列）

- **当** 用户选择折线图类型且只选择一个 Y 轴字段
- **那么** 系统生成折线图配置
- **并且** X 轴显示分类或时间字段值
- **并且** Y 轴显示数值字段值
- **并且** 图表正确渲染

#### 场景：渲染折线图（多系列）

- **当** 用户选择折线图类型且选择多个 Y 轴字段
- **那么** 系统生成多系列折线图配置
- **并且** X 轴显示分类或时间字段值
- **并且** Y 轴显示数值字段值
- **并且** 每个 Y 轴字段作为一条折线显示
- **并且** 不同折线使用不同颜色和样式区分

#### 场景：渲染饼图

- **当** 用户选择饼图类型
- **那么** 系统生成饼图配置
- **并且** 按分类字段分组
- **并且** 显示数值字段的占比
- **并且** 图表正确渲染

#### 场景：渲染散点图

- **当** 用户选择散点图类型
- **那么** 系统生成散点图配置
- **并且** X 轴和 Y 轴分别显示两个数值字段
- **并且** 图表正确渲染

#### 场景：渲染条形图

- **当** 用户选择条形图类型
- **那么** 系统生成条形图配置
- **并且** Y 轴显示分类字段值
- **并且** X 轴显示数值字段值
- **并且** 图表正确渲染

#### 场景：数据聚合

- **当** 用户选择分类字段进行分组
